# Universal File Viewer

Просмотрщик файлов на Python / PyQt6: двухпанельный интерфейс — слева окно просмотра, справа дерево файлов с сортировкой по имени, дате и типу. Всё содержимое отображается программно внутри окна приложения, внешние программы не запускаются.

## Демонстрация
Видео-демонстрация работы программы - `univiewer-demo_...mp4`

## Поддерживаемые форматы

| Категория | Форматы |
|---|---|
| Текст и код | txt, py, json, md, xml, html, css, js, c, cpp, h, java, sh, ini, yaml, toml, log и др. |
| Markdown / HTML | md, markdown, html, htm (рендеринг внутри приложения) |
| PDF | pdf (извлечение текста, постраничная навигация) |
| Документы Word | docx, odt, doc (doc и odt — best-effort без внешних утилит) |
| Электронные книги | epub, fb2 (текст, картинки, поэзия — рендеринг внутри приложения) |
| Презентации | pptx, ppsx (слайды с текстом, таблицами и картинками) |
| Изображения | png, jpg/jpeg, gif (в т.ч. анимированные), bmp, ico, tiff, webp, svg |
| Видео / аудио | mp4, avi, mkv, mov, webm, mp3, wav, ogg, flac, m4a и др. (встроенный QMediaPlayer) |
| Таблицы | csv, xlsx |
| Архивы | zip, tar, tar.gz, tar.bz2, tar.xz (список содержимого) |
| Неизвестные | бинарные файлы — hex-дамп; похожие на текст — текстовый просмотр |

## Установка на Ubuntu

```bash
sudo apt update
sudo apt install -y python3-venv python3-pip \
    libgl1 libegl1 libxkbcommon0 libxcb-cursor0 libdbus-1-3 \
    gstreamer1.0-plugins-base gstreamer1.0-plugins-good \
    gstreamer1.0-plugins-bad gstreamer1.0-libav

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Пакеты `gstreamer1.0-*` нужны для бэкенда Qt Multimedia на Linux (декодеры видео/аудио). Графические библиотеки (`libgl1`, `libxcb-cursor0` и др.) — зависимости Qt6 в окружении без системного PyQt6.

## Запуск

```bash
python main.py                 # откроется домашняя папка
python main.py /путь/к/папке   # открыть конкретную папку
```

## Использование

- Двойной клик по файлу — открыть в просмотрщике; по папке — войти в неё.
- Кнопки «Up» / «Home» и выпадающий список сортировки (Name / Type / Date) над деревом.
- Фильтр по имени и показ скрытых файлов — там же.

## Структура проекта

```
main.py                     точка входа
universal_viewer/
    mainwindow.py           главное окно, панели, меню
    filetree.py             панель дерева файлов и сортировка
    filetypes.py            сопоставление расширений и категорий
    utils.py                кодировки, форматирование
    viewers/                вьюеры по типам файлов + фабрика
tools/
    make_test_files.py      генерация тестовых файлов
    smoke_test.py           автономный smoke-тест всех вьюеров
```

## Ограничения

- `.doc` (бинарный формат Word 97) извлекается эвристически: простые документы читаются корректно, сложные могут дать частичный текст.
- Воспроизведение медиа зависит от кодеков, установленных в системе (см. gstreamer-пакеты выше).
- Очень большие файлы текста/CSV показываются с обрезкой (первые ~5 МБ / 5000 строк), о чём сообщается баннером.
